`Tuffy.ttf` is a small Latin font bundled for a self-contained demo. It was
copied unchanged from `fontdb` 0.24.0 (`tests/fonts/Tuffy.ttf`). The authors'
public-domain dedication and fallback permission are in `Tuffy-LICENSE.txt`.
Source: https://github.com/RazrFalcon/fontdb/tree/v0.24.0/tests/fonts

`NotoSansSC-Regular.otf` is the unmodified Simplified Chinese subset of Noto
Sans CJK, bundled as the application's default font so Chinese book titles and
UI labels render on machines without installed CJK fonts. Font family: Noto Sans SC.
It is embedded by Slint and supplied to the Kindle backend.

Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf
License: SIL Open Font License 1.1, included in `NotoSansSC-LICENSE.txt`.
Additional fonts can still be registered with `--font /path/font.ttf`.
